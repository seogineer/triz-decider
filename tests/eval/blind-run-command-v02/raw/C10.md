## 모순 정의
측정기의 측정 정확도를 높이면 조작 용이성이 나빠진다.

## 적용 아이디어

### 원리 #34 폐기 및 회수
- 정밀 보정(캘리브레이션) 메뉴나 상세 설정 화면은 측정이 끝나거나 보정이 완료되면 화면·버튼 구성에서 자동으로 사라지게 해, 평소 조작 화면은 단순하게 유지한다.
- 고정밀 측정에만 필요한 부가 센서 모듈은 필요할 때만 장착하고 평소에는 분리해 두는 착탈식 구조로 만든다.

### 원리 #1 분할
- 정확도를 높이는 세부 설정(감도 조절, 다단계 보정 파라미터 등)과 일상 측정에 쓰는 기본 조작을 물리적으로 다른 패널이나 메뉴 계층으로 분리한다.
- "기본 모드(간단 조작)"와 "정밀 모드(전문가용 상세 설정)"를 명확히 나눠, 일반 사용자는 기본 모드만 다루도록 한다.

### 원리 #13 역발상
- 사용자가 직접 정밀도 관련 옵션을 조작하게 하는 대신, 기기가 측정 대상·환경을 자동 감지해 최적 정밀 설정을 스스로 선택하도록 한다.
- 사용자 입력을 늘리는 방향 대신, 기기가 먼저 질문(또는 추천값)을 던지고 사용자는 확인만 하는 방식으로 조작 흐름을 뒤집는다.

### 원리 #17 다른 차원으로
- 늘어난 정밀 기능을 본체의 버튼·메뉴 계층에 쌓는 대신, 별도의 앱이나 외부 디스플레이 레이어로 옮겨 본체 조작판 자체의 복잡도는 그대로 유지한다.
- 다이얼과 터치스크린처럼 입력 축을 분리해, 기능 수가 늘어도 한 화면·한 축에서 처리해야 하는 단계 수는 늘리지 않는다.

### 원리 #27 저가 단수명
- 복잡한 정밀 보정 로직을 사용자가 직접 조작하는 대신, 교체형 저가 보정 카트리지(또는 기준 샘플)로 만들어 "끼우기만 하면 자동 보정"되게 한다.
