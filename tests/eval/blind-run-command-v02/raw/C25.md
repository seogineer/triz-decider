## 모순 정의
공장 검사 공정의 측정 정확도(불량 검출력)를 높이면(검사 항목 증가) 검사에 걸리는 시간(시간 손실)이 나빠진다.

## 적용 아이디어

### 원리 #28 역학 대체
- 육안·수작업 위주 검사 항목을 머신비전(광학) 검사로 전환해, 여러 항목을 한 번의 스캔으로 동시에 판독한다.
- 초음파·열화상 등 비접촉 센서를 도입해 순차적으로 진행하던 항목별 검사를 병렬 측정으로 바꾼다.
- 검사원이 각 항목을 눈으로 확인하는 대신, 자기장·전자기장 기반 센서 태그로 부품 이력을 자동 기록해 판정 시간을 줄인다.

### 원리 #24 매개물
- 컨베이어 라인에 다항목 동시 측정이 가능한 멀티센서 게이트(매개 장치)를 설치해, 검사원이 항목마다 개별 스테이션을 거치지 않게 한다.
- AI 판독 소프트웨어를 검사원과 부품 사이의 매개체로 두어, 검사원은 소프트웨어의 종합 판정 결과만 확인한다.
- 다항목을 한 번에 고정·측정하는 전용 지그를 검사 시점에만 부착했다가 완료 후 제거한다.

### 원리 #32 색상 변화
- 불량 위험 부위에 온도·압력에 반응해 색이 변하는 인디케이터를 부착해, 세부 항목을 하나씩 재확인하지 않고 즉시 육안 판별한다.
- 형광 염료로 미세 균열·누출 부위를 표시해 정밀 검사 시간을 단축한다.
- 합격/불합격 판정을 색상 라벨로 자동 표시해 후속 분류·재검사 대기 시간을 줄인다.

### 원리 #34 폐기 및 회수
- 이미 여러 번 합격한 항목은 신뢰 기반 샘플링으로 검사 목록에서 동적으로 제외하고, 위험도 높은 항목에 자원을 집중한다.
- 검사 완료 후 소모성 지그·소모품을 즉시 자동 회수·재생해 다음 검사 준비 시간을 줄인다.

### 원리 #13 역발상
- 검사원이 부품을 스테이션마다 옮기는 대신, 부품을 고정하고 다수의 검사 장비(카메라·센서)가 부품 주위를 동시에 이동하며 각 항목을 병렬로 검사한다.
- 라인 끝 한 번에 전수 검사하는 대신, 공정 중간중간에 항목을 분산 배치해 검사(역배치)함으로써 최종 검사 부담을 줄인다.
