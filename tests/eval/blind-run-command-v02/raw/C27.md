## Contradiction Definition

Increasing the pump's **reliability** (by adding redundant valves) worsens **ease of manufacture** and **ease of repair**.

## Applied Ideas

### Principle #1 — Segmentation
- Split the redundant-valve manifold into standardized, independently pluggable cartridges instead of one integrated block, so each valve module can be built, tested, and later swapped without touching the others.
- Give each valve cartridge its own quick-disconnect interface (electrical/hydraulic) so a technician can pull and replace a single failed unit rather than disassembling the whole valve stack.

### Principle #11 — Beforehand Cushioning
- Rather than running all redundant valves continuously in parallel, keep the primary valve as the simple baseline and stage the backup valve as a normally-dormant reserve that only engages on a detected fault — this keeps day-to-day build/assembly close to a single-valve system while still providing the reliability cushion.
- Pre-install diagnostic access ports and pre-stock a standard spare-valve kit at the point of use, so a failure is compensated by a quick swap-in rather than a full teardown.

### Principle #13 — Inversion
- Instead of duplicating whole valves in the flow path, invert the redundancy concept: use one valve body with a switchable/reconfigurable flow path (redundant *paths* through shared hardware) rather than redundant *physical valves* — cutting part count while preserving fail-over capability.
- Invert what's fixed vs. removable for service: make the pump housing the simple, static element and the entire valve assembly a single slide-out cartridge, so servicing means removing one sub-assembly instead of accessing multiple valves individually.

### Principle #35 — Parameter Changes
- Replace some of the rigid mechanical redundant valves with flexible, self-sealing elements (e.g., duckbill or flapper check valves) that are inherently more fault-tolerant by material behavior, reducing the number of discrete mechanical parts needed for the same reliability.
- Use pressure- or temperature-responsive materials (e.g., shape-memory alloys) to build redundancy into the material's state-change behavior rather than into added valve count, simplifying both assembly and field service.
