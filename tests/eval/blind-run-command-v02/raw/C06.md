## 적용 아이디어

### 원리 #15 역동성 (2회 등장, 최우선)
- 모든 기능을 하나의 고정된 인터페이스/구조에 다 넣는 대신, **모듈을 서로 움직이거나 탈부착 가능한 여러 부분**으로 나눈다. 자주 쓰는 핵심 모듈은 본체에 고정하고, 특수 용도 모듈은 필요할 때만 결합하는 방식(하위 원리 2: "움직일 수 있는 여러 부분으로 나눈다").
- 작동 단계·사용자 목적에 맞춰 **UI/조작부가 스스로 재구성**되게 한다. 예: 사용자가 선택한 용도(모드)에 따라 메뉴 트리와 버튼 배치가 자동으로 단순화되어, 물리적 부품 수는 그대로여도 체감 복잡도는 줄어든다(하위 원리 1: "작동 단계마다 최적이 되도록 스스로 바뀌게 한다").
- 지금은 고정된 설정값(예: 고정 배선, 고정 회로 경로)을 용도별로 **재구성 가능하게** 바꿔, 하나의 하드웨어가 소프트웨어적으로 여러 형태를 흉내 내게 한다(하위 원리 3: "고정돼 있던 것을 움직이거나 바꿀 수 있게 한다").

### 원리 #29 공압 및 수압
- 여러 기능마다 별도 기계식 액추에이터/기어박스를 두는 대신, **하나의 공압·유압 라인으로 여러 동작을 구동**해 기구 구조 자체의 부품 수를 줄인다.
- 예: 다기능 툴에서 기계적 전환 레버를 여러 개 두는 대신 유체 압력 경로를 밸브로 전환해 하나의 구동부가 여러 기능을 담당하게 한다.

### 원리 #37 열팽창
- 기능 전환을 위한 별도 센서·모터를 추가하는 대신, **재료의 열팽창/열수축 특성 자체를 스위치나 액추에이터로 활용**해 전자·기계 부품 수를 줄인다.
- 예: 온도(또는 발열원)에 따라 형태가 바뀌는 바이메탈식 요소로 특정 부가 기능(과열 차단, 환기 조절 등)을 무전원·무회로로 구현한다.

### 원리 #28 역학 대체
- 기계적 스위치·버튼·기구적 전환장치로 기능을 늘려가는 대신, **광학·음향·전자기 신호**로 대체해 물리적 부품 수와 조작 단계를 줄인다.
- 예: 물리 버튼 다이얼 대신 근접 센서나 무선 신호로 모드를 전환하면, 겉보기 구조는 단순해지면서도 내부적으로는 다양한 용도를 지원할 수 있다.

### 원리 #34 폐기 및 회수
- 특정 용도에서만 필요한 부분(부속 모듈, 소모성 어댑터 등)은 **평소에는 장치에서 분리해두고 필요할 때만 결합**하는 구조로 만들어, 기본 장치 자체의 복잡도를 낮춘다.
- 예: 다용도 공구에서 특수 팁·부속을 본체와 분리 보관하다가 필요할 때만 장착하는 방식(다단 로켓처럼 "역할을 다한/아직 필요 없는 부분을 분리").
