## 모순 정의
드론의 비행 지속 시간(#15 작동 지속 시간 – 움직임)을 늘리려고 배터리를 키우면, 기체 무게(#1 움직이는 물체의 무게)가 늘어난다.

| 악화 | #1 움직이는 물체의 무게 | 배터리를 키우면 늘어나는 것은 비행 중인 드론(움직이는 물체) 자체의 질량이므로 해당 |

## 적용 아이디어

### 원리 #19 주기적 조치
- 연속 최대 추력 대신 호버링/순항 구간에서 모터 출력을 펄스식으로 조절(PWM 기반 간헐 추력)해 평균 소비전력을 낮추고, 같은 배터리 용량으로 비행시간을 늘린다.
- 임무 경로 중 일부 구간은 모터를 잠깐 정지하고 관성·활공으로 비행("쉬는 시간에 다른 작용 수행")해 에너지를 절약한다.
- 배터리 방전을 주기적 저부하-고부하 패턴으로 관리해 셀 효율을 높이고, 동일 무게 대비 실사용 가능 용량을 늘린다.

### 원리 #5 통합
- 배터리 팩을 별도 하우징 없이 기체 프레임·암(arm) 구조와 일체화한 구조전지(structural battery)로 만들어, 배터리 무게와 별도의 지지 구조 무게를 동시에 줄인다.
- 배터리를 동체의 하중 지지 부재로 겸용시켜 프레임 보강재를 생략한다.
- 여러 소형 배터리 셀을 기체 여러 지점에 분산 배치해 무게중심 조정용 별도 밸런스 웨이트를 없앤다.

### 원리 #34 폐기 및 회수
- 장거리 임무에서 이륙 시에만 쓰는 대용량 부스터 배터리를 일정 고도·시점에 분리(드롭)하고, 이후 순항용 소형 배터리로 전환하는 다단(스테이징) 설계를 적용한다.
- 방전이 끝난 배터리 셀을 비행 중 자동 분리·투하해 기체가 점차 가벼워지도록 한다.
- 착륙 후 소모된 배터리를 즉시 교체(hot-swap)하는 방식으로, 기체 자체에는 항상 필요한 최소 용량만 탑재한다.

### 원리 #31 다공성 소재
- 배터리 하우징·프레임을 다공성 경량 금속 폼으로 제작해 강성은 유지하면서 구조 무게를 줄인다.
- 다공성 방열 구조를 배터리 팩에 적용해 별도 방열판 없이 냉각 성능을 확보, 더 높은 에너지밀도 셀 채택을 가능하게 한다.
- 다공 구조의 기공에 배선이나 완충재를 채워 넣어 부품을 다기능화하고 추가 부품 무게를 없앤다.
