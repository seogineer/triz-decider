## 모순 정의
생산 라인의 **생산성**을 높이려고 기능을 늘렸더니, 그 결과 **설비 조작**이 어려워졌다.

## 적용 아이디어

### 원리 #28 역학 대체
- 다수의 물리 스위치·레버·다이얼로 늘어난 기능을 조작하는 대신, 터치스크린 HMI나 센서 기반 자동 인식(광학·전자기)으로 조작 방식을 대체해 손으로 다뤄야 하는 물리적 조작점 수를 줄인다.
- 설비가 현재 어떤 기능/모드로 동작 중인지 소리·조명(색상 LED)으로 알려줘, 조작자가 복잡한 상태를 눈으로 일일이 추적하지 않게 한다.
- 무선 신호 기반 원격 모드 전환을 도입해, 기계적으로 설정을 바꿔야 하는 조작 부담을 없앤다.

### 원리 #1 분할
- 늘어난 기능들을 독립적으로 켜고 끌 수 있는 모듈로 분리해, 한 작업자가 특정 공정 단계에서는 해당 모듈의 조작만 마주하도록 한다(전체 기능을 한 화면·한 패널에 몰아넣지 않음).
- 조작 패널을 기능별 서브 유닛으로 나눠, 필요한 모듈만 조립/장착해 쓰고 불필요한 기능 모듈은 물리적으로 탈거할 수 있게 한다.
- 복잡한 설정 절차를 작은 독립 단계로 쪼개 각 단계마다 단순한 확인만 요구하는 방식으로 재설계한다.

### 원리 #7 포개기
- 조작 UI를 기본(자주 쓰는 핵심 기능)과 고급(신규로 추가된 부가 기능)으로 계층화해, 평소에는 기본 화면만 보이고 고급 기능은 메뉴 안에 포개 넣어 필요할 때만 펼치게 한다.
- 자주 쓰지 않는 신규 기능의 조작 버튼은 상위 메뉴 안에 중첩시켜, 초기 화면의 조작 요소 수를 늘어난 기능 수만큼 늘리지 않는다.

### 원리 #19 주기적 조치
- 늘어난 기능 전체를 상시 모니터링·조작하게 하지 않고, 각 기능이 실제로 개입이 필요한 시점에만 알림·조작 요청을 주기적으로 띄운다(예: 상태 이상 시에만 팝업).
- 여러 기능의 파라미터 점검을 연속 조작이 아니라 일정 주기마다 한 번씩 일괄 확인하는 루틴으로 바꿔, 조작자가 항상 여러 기능을 동시에 신경 쓰지 않게 한다.

### 원리 #12 등퍼텐셜
- 새로 추가된 기능마다 조작 방식(버튼 배치, 인터페이스 스타일, 조작 순서)을 통일해, 기능 간 전환 시 조작자가 새로 학습해야 하는 "낙차"를 없앤다.
- 모든 기능의 조작 패널을 동일한 높이·동일한 UI 문법으로 표준화해, 기능이 늘어도 조작자가 매번 다른 조작 체계에 적응하는 부담이 생기지 않게 한다.
