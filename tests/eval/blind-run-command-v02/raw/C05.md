## 모순 정의
냉각 팬 시스템의 온도(냉각 성능)를 높이면(개선하면) 소음이 나빠진다.
팬을 강하게 돌려 냉각 성능을 높일수록 소음이 커진다.

## 적용 아이디어

### 원리 #35 매개변수 변화
- 하위 원리 "온도를 바꾼다": 공기가 아닌 냉매(액체 냉각)를 도입해 열전달 매체를 바꾸면, 같은 발열량을 더 낮은 팬 회전수로도 배출할 수 있어 소음원인 고속 회전 자체가 줄어든다.
- 하위 원리 "유연성의 정도를 바꾼다": 팬 블레이드 재질/형상의 강성을 온도·부하에 따라 가변화해, 저부하 구간에서는 유연한 블레이드로 저소음 운전을 하고 고부하 구간에서만 강성을 높여 풍량을 확보한다.

### 원리 #2 추출
- "소음원을 분리한다": 소음의 근원인 팬 모터·베어링을 방진/방음 마운트로 본체에서 분리하거나 별도의 방음 하우징(덕트)에 넣어, 냉각 성능은 유지하면서 소음만 저감한다.
- "필요한 부분만 골라 쓴다": 다수의 소형 팬을 분산 배치해 각 팬은 낮은 회전수로만 구동하고, 발열이 집중된 구역에만 선택적으로 풍량을 집중시켜 전체 최고 회전수(=최대 소음원)를 낮춘다.

### 원리 #24 매개물
- "전달을 매개하는 대상을 둔다": 팬과 히트싱크 사이에 히트파이프나 베이퍼 챔버 같은 열전달 매개체를 넣어, 열을 빠르게 확산시켜 팬 회전수를 덜 올려도 동일한 냉각 효과를 얻게 한다.
- "매개체를 임시로 붙여 쓴다": 부하가 순간적으로 튈 때만 상변화 물질(PCM)이 열을 흡수해 팬이 즉시 고속 회전으로 대응할 필요를 줄인다.

### 원리 #22 전화위복
- "해로운 요인을 이용해 좋은 효과를 만든다": 팬 소음을 능동소음제어(ANC)의 입력 신호로 활용해 역위상 음파를 발생시켜 체감 소음을 상쇄한다.
- "해로운 요인의 세기를 해가 되지 않을 정도까지 키운다": 오히려 팬을 특정 공진 주파수를 피해 더 높은 초음파 대역(가청 영역 밖)으로 설계해 소음을 사람이 인지하지 못하는 대역으로 옮긴다.

### 원리 #21 고속 처리
- "해로운 단계를 빠르게 지나간다": 팬을 지속적으로 강하게 돌리는 대신, 온도가 임계치를 넘을 때만 짧고 강하게(버스트) 고속 회전시켜 소음이 나는 시간 자체를 최소화하고, 평상시에는 저속·저소음으로 운전한다.
