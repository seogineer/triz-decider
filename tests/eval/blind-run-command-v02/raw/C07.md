## 모순 정의
공정의 자동화 정도(#38 자동화 정도)를 높이면 설비의 장치 복잡성(#36)과 부품 수(#26)가 나빠진다.

## 적용 아이디어

### 원리 #35 매개변수 변화
- 하드웨어 기구(캠, 링크, 전용 지그)를 추가해 다품종에 대응하는 대신, 소프트웨어 파라미터(속도·경로·힘 제어값)만 바꿔 같은 그리퍼·같은 축으로 여러 작업을 처리한다. → "유연성의 정도를 바꾼다" 하위 원리 적용.
- 제품별 전용 고정 지그를 늘리는 대신, 압력이나 강성을 전기적으로 바꿀 수 있는 가변 클램프(예: 공압 압력 제어)를 써서 지그 종류 수 자체를 줄인다.

### 원리 #13 역발상
- 로봇/공구 쪽에 다축 이동 기구를 계속 추가하기보다, 공구는 고정하고 워크피스를 이송 컨베이어·인덱스 테이블로 움직이게 해 구동부 수를 줄인다.
- 매 공정 단계마다 별도 자동화 유닛을 붙이는 대신, 하나의 고정 스테이션으로 제품이 순환해 오도록 흐름을 뒤집는다.

### 원리 #15 역동성
- 공정별 전용 부품으로 설비를 채우는 대신, 소수의 재구성 가능한 모듈(가변 그리퍼, 교체형 헤드)을 만들어 여러 공정에 재사용한다.
- 완전히 고정된 자동화 라인 대신, 필요 시 위치·각도를 바꿀 수 있는 가변 노즐/암 구조로 전용 부품 수를 줄인다.

### 원리 #24 매개물
- 로봇과 제품 사이에 표준 인터페이스(범용 어댑터, 퀵체인지 플레이트)를 두어, 제품마다 별도의 전용 기구를 만드는 대신 어댑터만 교체한다.
- 복잡한 기계식 연동 대신 PLC/소프트웨어를 매개체로 삼아 신호로 기구 간 협조를 제어함으로써 기계적 연결부(링크, 캠) 수를 줄인다.

### 원리 #10 사전 조치
- 자동화 설비가 실시간으로 대응하기 위해 복잡한 감지·전환 기구를 추가하는 대신, 부품 피더에 순서대로 미리 정렬·적재해 두어 설비가 단순 동작만 반복하면 되게 한다.
- 제품 교체 시 필요한 지그·파라미터 세트를 미리 구성해 두고(사전 셋업 키트), 교체 때마다 부품을 추가하지 않고 미리 준비된 모듈만 갈아 끼운다.
