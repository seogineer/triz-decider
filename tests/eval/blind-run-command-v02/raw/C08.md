## 모순 정의
압력 용기의 무게(벽 두께 감소)를 줄이면 견디는 압력, 즉 강도가 나빠진다.

## 파라미터 매핑
| 구분 | 파라미터 | 근거 |
| --- | --- | --- |
| 개선 | #2 정지된 물체의 무게 | 압력 용기는 보통 설치·운용 중 고정된 구조물이며, "벽을 얇게 해 무게를 줄인다"는 요구가 정확히 이 파라미터(자중 감소)에 해당함 |
| 개선(보조) | #1 움직이는 물체의 무게 | 운송용·이동형 탱크(가스 실린더 등)처럼 용기가 움직이는 경우를 대비한 후보 |
| 악화 | #14 강도 | "견디는 압력이 약해진다"는 곧 외력(내압)에 파손되지 않고 버티는 능력이 떨어진다는 뜻으로 강도 정의와 정확히 일치 |
| 악화(보조) | #11 응력 또는 압력 | 벽이 얇아지면 같은 내압에서도 벽 내부 응력이 커진다는 관점의 보조 후보 |

## 적용 아이디어

### 원리 #10 사전 조치 (필요한 변화를 미리 수행 / 대상을 미리 편한 자리에 둠)
- **오토프레티지(autofrettage)**: 용기를 실제 사용압보다 높은 압력으로 미리 한 번 가압해 벽 내부에 압축 잔류응력을 형성해 둔다. 그러면 벽을 얇게 해도 실제 운용 중 인장응력이 이 잔류 압축응력을 먼저 상쇄해 더 높은 내압을 버틸 수 있다.
- **와인딩 프리텐션**: 필라멘트 와인딩형 복합 용기에서 섬유를 감을 때 미리 인장력(프리텐션)을 걸어 라이너에 압축력을 걸어둔다. 내압이 걸리기 전에 이미 "버틸 준비"가 되어 있는 상태를 만드는 것.

### 원리 #40 복합 재료 (단일 재료 → 복합 재료)
- **Type III/IV 복합 압력 용기 구조**: 얇은 금속(또는 폴리머) 라이너를 기밀층으로만 쓰고, 그 바깥을 탄소섬유·유리섬유 복합재로 필라멘트 와인딩해 하중을 전담시킨다. 동일 내압 기준으로 전강 금속 벽 대비 무게를 크게 줄이면서 강도를 확보.
- **다층 적층 벽**: 균일한 두꺼운 단일 금속판 대신, 얇은 고강도강 층 + 섬유강화 복합층 + 부식방지 라이너를 적층해 각 층이 다른 역할(기밀·강도·내식)을 분담하도록 설계.

### 원리 #28 역학 대체 (기계적 수단 → 다른 장/수단으로 대체)
- **실시간 응력 모니터링 기반 설계 여유 축소**: 벽에 변형률 게이지·광섬유 센서를 매립해 실제 응력 상태를 상시 측정하고, 그 데이터를 근거로 종전에는 "혹시 모를 위험"에 대비해 두던 과도한 두께 여유를 줄인다. 즉 기계적 안전 여유를 전자기적 감지 시스템으로 일부 대체.
- **자기유변/전기유변 복합 라이너**: 특정 조건에서만 자기장·전기장을 가해 국소적으로 강성을 높이는 스마트 재료를 활용해, 평상시엔 얇고 가볍지만 고압이 걸리는 순간에만 강성이 커지도록 하는 방식 검토.

### 원리 #27 저가 단수명 (값비싼 대상 하나 → 값싸고 수명 짧은 다수)
- **교체형 얇은 벽 카트리지**: 고압 용기 전체를 두껍게 만들어 장기간 쓰는 대신, 얇고 가벼운 벽을 가진 저가 카트리지형 용기(예: 1회용·수회용 가스 실린더)로 설계하고 일정 사용 횟수·기간 후 통째로 교체한다. 무게는 최소화하되 "평생 버텨야 한다"는 요구 자체를 없앤다.
- **소모성 내부 라이너**: 압력을 직접 받는 얇은 내부 라이너만 소모품으로 취급해 주기적으로 교체하고, 외부 구조는 경량 지지 역할만 하도록 역할을 분리.

### 원리 #18 기계적 진동 (진동을 가함 / 공진 이용)
- **진동 보조 와인딩·성형 공정**: 복합재 벽을 제작할 때 진동을 가하며 섬유·수지를 다져 기공(void)을 줄이면, 동일 두께에서 강도가 올라가 더 얇게 설계할 여유가 생긴다.
- **진동 기반 비파괴 검사**: 초음파(고주파 기계적 진동)로 얇아진 벽의 결함·박리를 상시 또는 주기적으로 검사해, 실제 결함이 없다는 것을 확인하면서 설계 안전율을 낮춰 무게를 더 줄인다.

## 다음 단계
- 용기가 고정형인지 이동형인지에 따라 개선 파라미터를 #2(정지)로 확정할지 #1(이동)도 함께 볼지 재확인.
- "견디는 압력"이 재료 파손 한계(강도, #14)를 말하는지, 아니면 특정 응력 수준 초과 여부(#11)를 말하는지에 따라 원리 우선순위가 달라질 수 있으므로, 실제 실패 모드(파열 vs 항복 vs 피로)를 명확히 하면 매핑을 더 좁힐 수 있음.
- 오토프레티지·복합 와인딩 등은 기존 제조 공정·규격(ASME, ISO 11439 등) 적합성 검토가 필요.
