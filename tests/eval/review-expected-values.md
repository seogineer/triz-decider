# 평가 케이스 기대값 검토용 요약

`tests/eval/cases.yaml`의 32개 케이스에서 **문제 문장**과 **기대 파라미터**만 뽑은 표입니다. 기대값은 케이스를 만든 쪽(Claude)이 정한 것이라 다른 사람의 검토가 필요합니다. 2026-09-24에 9개 행을 의미 기준으로 한 번 고쳤습니다(`results-v0.1.md`의 "기대값 수정" 참고).

## 검토 방법
1. 각 행을 읽고 마지막 칸에 **O**(맞음), **X**(틀림 또는 이상함), 또는 **수정안**을 적는다. 예: `X: 개선은 #14 강도가 맞음`
2. 파라미터의 뜻은 `skills/triz-analysis/references/parameters-39.md`를 본다.
3. 기대값은 **허용 목록**이다. 한 칸에 여러 개면 그중 하나만 맞아도 정답으로 친다.
4. "움직이는/고정된" 쌍(1·2, 3·4, 5·6, 7·8, 15·16, 19·20)은 문장만으로 구분하기 어려워 둘 다 허용하기도 했다.
