## 적용 아이디어

### 원리 #15 역동성
- **범용 가변 모듈 하나로 통합** (하위 원리: 작동 단계마다 대상이 스스로 바뀌게 함): 공정 단계별로 전용 장치를 두지 않습니다. 그리퍼나 지그, 노즐을 레시피에 따라 형상이나 위치가 바뀌는 하나의 가변 유닛으로 바꾸면 부품 종류와 수가 줄어듭니다.
- **경직된 구조를 유연하게** (하위 원리: 경직된 대상을 유연하게 만듦): 고정 컨베이어와 분기 장치를 여러 개 두는 대신, 서보로 경로를 바꾸는 하나의 유연 이송부를 씁니다.

### 원리 #24 매개물
- **임시로 붙였다 떼는 매개체** (하위 원리: 매개체를 임시로 붙여 쓰고 나중에 뗌): 제품마다 필요한 기능(고정, 위치 결정)을 설비 본체에 상시 내장하지 않고, 교체형 팰릿이나 툴 어댑터에 담습니다. 본체는 단순하게 유지되고 복잡성은 소모성 매개체로 옮겨집니다.
- **전달·작용을 매개하는 대상** (하위 원리: 두 대상 사이 작용을 매개): 단계 사이에 센서와 액추에이터를 일대일로 배선하는 대신, 공통 데이터 버스나 매개 게이트웨이를 두어 상호 의존을 줄입니다.

### 원리 #10 사전 조치
- **미리 수행해 두기** (하위 원리: 필요한 변화를 미리 수행): 공정 중에 자동으로 정렬하거나 위치를 잡는 장치를 넣는 대신, 앞 공정이나 자재 단계에서 정렬된 상태로 공급합니다(예: 미리 배열된 트레이). 그러면 정렬용 자동화 부품이 필요 없어집니다.
- **필요한 자리에 미리 배치** (하위 원리: 지체 없이 작동하도록 미리 배치): 자재를 사용 위치에 미리 놓아 이송 장치 단계를 줄입니다.

### 원리 #35 매개변수 변화
- **물리적 상태나 유연성 변경** (하위 원리: 물리적 상태·유연성 정도 변경): 고체 부품을 기계적으로 집고 옮기는 대신 액상·분말 상태로 공급하거나 진공 흡착을 씁니다. 취급용 기구 부품이 줄어듭니다.
- **조건에 따라 성질이 바뀌는 소재** (하위 원리: 유연성 정도 변경): 강성이 바뀌는 소프트 그리퍼처럼, 제품별 전용 핑거를 여러 개 두지 않고 한 부품으로 대응합니다.

### 원리 #13 역발상
- **움직이던 부분과 고정된 부분을 맞바꿈** (하위 원리: 움직이던 부분을 고정하고 고정돼 있던 부분을 움직이게 함): 여러 스테이션으로 제품을 옮기는 대신 제품은 고정하고 공구 헤드가 이동하게 합니다. 이송 기구와 스테이션 수가 줄어듭니다. 반대로 공구를 고정하고 제품을 움직이는 방식도 검토할 수 있습니다.
- **반대 동작으로 대체** (하위 원리: 요구 동작 대신 반대 동작): 부품을 자동으로 정렬하는 장치 대신, 정렬이 필요 없는 방향으로 공정을 바꿉니다.
