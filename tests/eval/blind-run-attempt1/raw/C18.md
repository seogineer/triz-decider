## 1. 모순 정의

**기술적 모순**
- 포장재를 얇게 하면 재료가 절약되지만(개선), 충격 흡수와 보호력이 떨어져 파손이 늘어납니다(악화).
- 포장재를 두껍게 하면 제품은 보호되지만 재료비, 무게, 부피가 늘어납니다.

**TRIZ 39개 파라미터로 옮기면**
- 개선 파라미터: **#23 물질의 손실**, 또는 #1 움직이지 않는 물체의 무게
- 악화 파라미터: **#30 물체에 작용하는 유해 요인**(파손), 또는 #14 강도

**물리적 모순**: 포장재는 충격 순간에는 두껍고 단단해야 하고(보호), 평상시에는 얇고 적어야 합니다(절약).

## 2. 모순 매트릭스가 제시하는 발명 원리

| 원리 | 적용 아이디어 |
|---|---|
| **#40 복합재료** | 얇은 골판지에 에어셀이나 발포층을 겹칩니다. 얇은 층을 여러 겹 쌓아 두꺼운 단일층과 같은 흡수력을 냅니다. |
| **#1 분할** | 전체를 감싸지 않고 모서리, 꼭짓점 같은 취약 부위에만 보강 코너 패드를 씁니다. |
| **#3 국소적 품질** | 충격이 집중되는 곳만 두껍게 하고 나머지는 얇게 합니다. 낙하 시험에서 파손 위치를 먼저 찾아 두께를 배분합니다. |
| **#15 동적성** | 평소에는 납작하다가 충격이나 공기 주입 시 부풀어 오르는 인플레이터블 포장재를 씁니다. |
| **#31 다공성 재료** | 벌집(허니콤) 구조나 리브 구조로 재료는 줄이고 강성은 유지합니다. 소재를 늘리는 대신 형상으로 강도를 확보합니다. |
| **#35 물리·화학적 상태 변화** | 충격에 강해지는 전단경화(STF) 소재나 성형 펄프로 바꿉니다. |
| **#2 추출(분리)** | 제품 자체를 보강해서 포장 부담을 줄입니다. 예를 들어 깨지기 쉬운 돌출부를 분리 포장하거나 제품 설계를 바꿉니다. |
| **#10 사전 조치** | 제품을 박스 중앙에 띄워 고정하는 서스펜션 포장으로 미리 충격 경로를 차단합니다. |

## 3. 물리적 모순 분리 원리 적용

- **공간 분리**: 취약 부위는 두껍게, 나머지는 얇게 만듭니다(#3, #1).
- **시간 분리**: 충격 시에만 보호 기능이 작동하게 합니다(#15, #35).
- **구조 분리**: 재료의 양이 아니라 구조(허니콤, 아치, 리브)로 강성을 확보합니다(#31).

## 4. 이상적 최종 결과(IFR)

포장재가 없어도(또는 극소량이어도) 제품이 스스로 충격을 견뎌 파손이 0이 되는 상태입니다. 여기서 자원을 찾아보면 다음과 같습니다.
- 제품 자체의 형상과 재질을 충격 흡수 구조로 바꿉니다.
- 이미 있는 자원인 빈 공간, 공기, 외박스의 구조를 씁니다.
- 운송 방식(팔레트 적재, 진동 경로)을 바꿔 충격 입력을 줄입니다.

## 5. 권장 순서

1. **원인 파악부터 합니다.** 파손이 낙하, 진동, 압축(적재) 중 어디서 오는지, 어느 부위인지 분류합니다. 대응이 서로 다릅니다.
2. **빠르게 적용할 안**: 취약 부위만 국소 보강(#3, #1)하고 나머지는 얇게 유지합니다. 재료 절감 효과를 대부분 유지하면서 파손을 크게 줄일 가능성이 높습니다.
3. **구조 개선안**: 허니콤이나 리브 구조 또는 성형 펄프로 바꿔서 소재 총량을 줄이면서 강성을 확보합니다(#31, #40).
4. **근본 해결안**: 제품 측 보강이나 서스펜션 포장(#2, #10)으로 포장 의존도를 낮춥니다.
5. **검증**: ISTA나 KS 규격의 낙하·진동 시험으로 안별 파손률, 재료비, 물류비(부피와 무게)를 비교합니다. 파손으로 인한 반품과 재발송 비용이 절약한 재료비보다 크면 손해이니, 총비용 기준으로 판단하세요.

제품 종류(깨짐, 눌림, 긁힘 등)와 파손 패턴을 알려주시면 위 원리 중 가장 맞는 것으로 좁혀 구체안을 드리겠습니다.
