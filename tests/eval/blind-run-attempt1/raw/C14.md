## 1. 모순 정의

**기술적 모순**
- 개선하려는 특성: 속도, 생산성 (전송률 ↑)
- 악화되는 특성: 신뢰성, 정보 손실, 정확도 (오류·손실 ↑)

**물리적 모순**
- 전송 속도는 처리량을 위해 **높아야 하고**, 신호 마진과 버퍼 여유를 위해 **낮아야** 한다.

## 2. 이상적 최종 결과 (IFR)

전송 속도는 최대인데, 추가 비용이나 복잡도 없이 오류와 손실이 저절로 0이 되는 상태.

## 3. 발명 원리 적용

아래 원리는 TRIZ 원리의 일반적 매핑이고, 모순 매트릭스 셀 값은 직접 대조하지 않았습니다.

| 원리 | 적용 방안 |
|---|---|
| **11. 사전 완충** | FEC(순방향 오류 정정), CRC, 패리티, 리드-솔로몬 부호로 오류를 미리 대비 |
| **35. 파라미터 변경** | 변조 차수를 낮추거나 심볼 레이트를 내리고, 대신 채널 수를 늘림 |
| **1. 분할** | 데이터를 작은 청크로 나눠 청크마다 체크섬을 붙이고 병렬 채널로 전송. 오류 시 해당 청크만 재전송 |
| **10. 사전 조치** | 링크 트레이닝, 프리엠퍼시스/이퀄라이제이션, 핸드셰이크로 속도를 올리기 전에 채널 상태를 조정 |
| **15. 동적성** | 채널 품질에 따라 속도와 변조 방식을 실시간으로 바꿈 (적응형 속도, 혼잡 제어) |
| **23. 피드백** | ACK/NACK, 선택적 재전송(SACK)으로 손실 구간만 복구 |
| **24. 중개자** | 버퍼, 큐, 페이싱으로 송수신 속도 차이를 흡수 |
| **2. 추출** | 압축이나 중복 제거로 보낼 비트 자체를 줄여 같은 처리량을 낮은 심볼 속도로 달성 |

## 4. 분리 원리로 본 해법

- **시간 분리**: 평소엔 고속으로 보내고, 오류율이 임계치를 넘으면 자동으로 감속한다.
- **조건 분리**: 채널이 깨끗하면 고속·저중복, 잡음이 많으면 저속·고중복으로 바꾼다.
- **공간 분리**: 중요 데이터는 보호된 저속 경로로, 대량 데이터는 고속 경로로 보낸다.
- **스케일 분리**: 심볼 레이트는 낮게 두고 병렬화로 총 처리량을 확보한다.

## 5. 권장 적용 순서

1. **원인 계측**: 오류가 신호 품질(잡음, 지터, 클럭) 때문인지, 버퍼 오버플로와 혼잡 드롭 때문인지 먼저 구분한다. 원인에 따라 효과가 큰 원리가 다르다.
2. **원인이 신호 품질이면**: 원리 35, 10, 11 순으로 적용한다. 속도를 약간 낮추고 병렬화하며, 이퀄라이제이션과 FEC를 추가한다.
3. **원인이 버퍼·혼잡이면**: 원리 24, 15, 23 순으로 적용한다. 버퍼 크기를 늘리고 페이싱과 혼잡 제어를 넣고 선택적 재전송을 쓴다.
4. **공통으로**: 원리 1을 적용해 청크 단위 검증과 부분 재전송 구조를 만든다.
5. **적응형 제어(원리 15)로 마무리**: 고정 속도 대신 오류율 기반 자동 조절로 처리량과 신뢰성의 균형점을 유지한다.

프로토콜, 매체(이더넷, 무선, 시리얼, 스토리지 I/O 등), 오류 유형을 알려주시면 위 원리를 구체적인 설정값과 설계로 좁혀 드리겠습니다.
