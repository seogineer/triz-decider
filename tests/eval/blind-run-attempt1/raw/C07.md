## 1. 모순 정의

- **개선 파라미터:** 자동화 수준, 생산성 (TRIZ 39개 파라미터의 #38 자동화 정도, #39 생산성)
- **악화 파라미터:** 장치의 복잡성 (#36), 물질·부품의 양 (#26)
- **기술적 모순:** 공정을 자동화하면 사람 손이 줄지만, 설비 구조가 복잡해지고 부품 수가 늘어난다.
- **물리적 모순:** 설비는 자동화 기능을 갖춰야 하므로 부품이 많아야 한다. 그러면서 동시에 단순하고 부품이 적어야 한다.
- **이상적 최종 결과(IFR):** 부품이 늘지 않는데도 공정이 스스로 자동으로 진행된다.

## 2. 모순 매트릭스 기반 발명 원리

| 원리 | 적용 방향 |
|---|---|
| **#6 다기능성** | 부품 하나가 이송, 위치결정, 고정을 함께 맡는다. 예를 들어 그리퍼 하나가 클램프와 센서를 겸한다. |
| **#1 분할 / #5 통합** | 기능별로 흩어진 모듈을 하나의 표준 모듈로 묶는다. 공통 프레임 위에 모듈을 올려 배관과 배선을 줄인다. |
| **#2 추출** | 자동화에 꼭 필요한 기능만 남기고, 예외 처리용 부품은 분리해 별도 스테이션이나 사람에게 넘긴다. |

| **#10 사전 작용** | 앞 공정에서 제품을 미리 정렬하거나 방향을 잡아 두면 뒤 공정의 정렬 장치가 필요 없다. |
| **#24 중개자 / #22 전화위복** | 여러 제품이 함께 쓰는 공용 팔레트나 지그를 두고, 불량이나 편차를 피드백 신호로 활용한다. |

## 3. 우선 적용 조합

1. **기능 통합 (#6 + #5):** 부품 목록을 기능 기준으로 다시 분류하고, 한 부품이 두 기능 이상을 맡을 수 있는지 확인한다. 목표는 부품 수 20~30% 감축이다.
2. **기계를 소프트웨어로 (#35 + #28):** 캠, 링크, 리밋 스위치를 서보와 센서 기반 제어로 바꾼다. 하드웨어는 줄고 유연성은 늘지만, 제어 로직은 복잡해진다.
3. **공정 자체가 자동화를 돕게 (#25 + #10):** 이송과 정렬을 중력이나 형상 가이드로 해결한다. 앞 공정에서 자세를 미리 잡아 두면 뒤 공정의 정렬 장치를 없앨 수 있다.

## 4. 분리 원리 (물리적 모순)

- **공간 분리:** 복잡한 부분(제어, 센서)은 설비 밖의 통합 제어반이나 클라우드로 옮기고, 현장 설비는 단순한 실행부만 남긴다.
- **시간 분리:** 한 스테이션이 여러 공정을 시간차로 수행한다. 툴 체인저나 다기능 헤드가 그 예다.
- **조건 분리:** 정상 흐름은 완전 자동화하고, 드문 예외 케이스는 수동이나 별도 라인으로 처리한다. 이렇게 하면 예외 대응용 부품이 메인 설비에서 빠진다.

## 5. 실행 순서

1. 현재 BOM을 기능별로 분류하고, 자동화 때문에 추가된 부품을 식별한다.
2. 기능이 겹치거나 소프트웨어로 대체할 수 있는 부품을 표시한다.
3. 위 조합 1~3 중 비용이 낮은 것부터 파일럿 스테이션에 적용한다.
4. 부품 수, 고장 지점 수, 사이클 타임, 유지보수 시간으로 효과를 측정한다.

## 6. 주의

- 소프트웨어로 대체하면 하드웨어는 단순해지지만 제어와 검증 부담이 늘어난다. 복잡성이 이동할 뿐인지 확인해야 합니다.
- 이 분석은 설비 종류와 공정 조건을 모른 채 일반적으로 한 것입니다. 구체적인 공정(조립, 도장, 검사, 이송 등)과 제약(택트타임, 예산, 품질 기준)을 알려 주시면 원리별 구체안과 우선순위를 정리해 드리겠습니다.
