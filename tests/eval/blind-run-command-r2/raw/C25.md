## 모순 정의
공장 검사 공정의 검사 항목을 늘려 불량 검출 능력을 높이면 검사 소요 시간이 길어진다. 요청하신 대로 모순 문장 확인은 생략하고 진행했습니다.

## 파라미터 매핑
| 구분 | 파라미터 | 근거 |
| --- | --- | --- |
| 개선 | #28 측정 정확도 | 불량을 더 잘 잡는 것은 검사 결과의 정확도와 검출력이 올라가는 것입니다. |
| 개선 | #27 신뢰성 | 불량이 출하되지 않고 품질이 안정적으로 보증되는 면에서 보조 후보로 넣었습니다. |
| 악화 | #25 시간 손실 | 검사 사이클 타임과 소요 시간이 길어지는 것입니다. |
| 악화 | #39 생산성 | 검사가 병목이 되어 단위 시간당 처리량이 줄어듭니다. |

## 추천 원리 (행렬 조회 결과)
조회한 4개 조합 모두 원리가 있었고, `empty_pairs`와 `warnings`는 없었습니다. 등장 횟수 2회가 4개라서 출력 순서를 따라 상위 4개를 골랐습니다.

| 순위 | 원리 | 등장 횟수 |
| --- | --- | --- |
| 1 | #34 폐기 및 회수 | 2 |
| 2 | #28 역학 대체 | 2 |
| 3 | #32 색상 변화 | 2 |
| 4 | #10 사전 조치 | 2 |

## 적용 아이디어
### 원리 #34 폐기 및 회수
- 앞 단계 검사에서 이미 합격이 확인된 항목은 다음 단계에서 없앱니다. 하위 원리는 "역할을 다한 부분은 작동 중에 없앤다"를 적용했습니다. 예를 들어 공정 중 검사에서 치수를 확인했다면 최종 검사에서는 그 치수 항목을 생략합니다.
- 불량 이력이 없는 항목은 표본 검사로 바꾸거나 점검 주기를 늘립니다. 불량이 다시 나타나면 전수 검사로 되돌립니다.

### 원리 #28 역학 대체
- 접촉식·수작업 검사(게이지, 육안)를 광학·전자기 수단으로 바꿉니다. 하위 원리는 "기계적 수단을 광학·음향·열 수단으로 바꾼다"를 적용했습니다. 비전 카메라, 레이저 스캐너, 와전류 검사가 예입니다.
- 한 번의 광학 스캔이나 영상 촬영으로 여러 항목을 동시에 측정하게 하면 항목이 늘어도 시간은 늘지 않습니다.

### 원리 #32 색상 변화
- 하위 원리 "색소나 첨가제로 관찰하기 어려운 대상을 잘 보이게 한다"와 "형광 표지"를 적용해, 형광 침투제나 UV 조명으로 균열·누설·이물을 한눈에 드러냅니다.
- 조명 색이나 투명도를 바꿔 불량 부위의 대비를 키우면 판독이 빨라지고 재검이 줄어듭니다.

### 원리 #10 사전 조치
- 하위 원리 "필요한 변화를 필요한 때보다 먼저 수행해 둔다"에 따라, 검사 지그 세팅, 교정, 부품 정렬, 바코드 인식을 검사 대기 시간에 미리 끝냅니다.
- 하위 원리 "필요한 순간 지체 없이 작동하도록 미리 편한 자리에 둔다"에 따라, 검사 도구와 시료를 사용 순서대로 배치한 트레이를 씁니다. 준비와 교체 시간이 줄어듭니다.

## 다음 단계
- 매핑 재검토: 검사 시간 중 어느 부분이 늘었는지 먼저 확인해야 합니다. 준비·교체 시간이면 #10, 측정 시간이면 #28, 판독 시간이면 #32가 우선입니다. 항목 중복이 원인이면 #34가 우선입니다.
- 검증: 항목별 검사 시간과 검출 기여도(불량 검출 건수)를 표로 만들어, 시간은 길고 기여는 낮은 항목부터 적용 대상으로 정합니다.
- 적용 후에는 검출률(누락률)과 검사 사이클 타임을 함께 추적해, 시간이 줄어도 검출력이 유지되는지 확인합니다.
