## 모순 정의
측정기의 측정 정확도를 높이려고 기능을 추가하면 조작이 어려워진다. (사용자가 이미 확인한 문장이라 그대로 진행했습니다.)

## 파라미터 매핑
| 구분 | 파라미터 | 근거 |
| --- | --- | --- |

| 악화 | #33 작동 용이성 | "조작이 어려워졌다"가 사용 편의와 조작성 저하에 해당한다. |
| 악화 | #36 장치 복잡성 | 기능이 늘면 설정 항목과 사용 절차가 늘어 구조와 사용법이 복잡해진다. 조작이 어려워진 원인으로 보고 후보에 넣었다. |

## 적용 아이디어
### 원리 #34 폐기 및 회수
- 하위 원리 "역할을 다한 부분은 작동 중에 없애거나 다른 형태로 바꾼다"를 적용합니다. 정밀 모드에서 보정이나 영점 조정 같은 고급 단계는 한 번 끝나면 화면에서 자동으로 사라지고 결과값만 남깁니다.
- 하위 원리 "소모된 부분은 작동 중에 바로 채우거나 복원한다"를 적용합니다. 보정값이나 필터 설정처럼 사용자가 다시 입력해야 하는 항목은 측정이 끝나면 기본값으로 자동 복원합니다.

### 원리 #1 분할
- 하위 원리 "서로 독립적으로 움직이는 부분으로 나눈다"를 적용합니다. 기본 측정부와 고정밀 기능부를 분리해, 평소에는 기본 조작만 쓰고 정밀 기능은 필요할 때만 씁니다.
- 하위 원리 "쉽게 조립하고 분해할 수 있는 구조"를 적용합니다. 정밀 기능을 탈착식 모듈이나 별도 메뉴 계층으로 만들어, 필요한 사람만 붙이게 합니다.

### 원리 #13 역발상
- 하위 원리 "요구하는 동작 대신 그 반대의 동작을 한다"를 적용합니다. 사용자가 정밀 설정을 하는 대신 기기가 조건(온도, 자세, 대상 종류)을 스스로 감지해 설정하고, 사용자는 측정 버튼만 누릅니다.
- 하위 원리 "움직이던 부분을 고정하고 고정돼 있던 부분을 움직이게 한다"를 적용합니다. 측정기를 손으로 맞추는 대신 대상 쪽을 지그에 고정하고, 기기 쪽에서 정렬을 처리합니다.

### 원리 #17 다른 차원으로
- 하위 원리 "여러 층으로 쌓거나 2·3차원으로 움직이게 한다"를 적용합니다. 조작 인터페이스를 '간단/정밀' 층으로 겹쳐서, 기본 화면은 한 단계로 두고 정밀 옵션은 아래층에 둡니다.
- 하위 원리 "반대편이나 이웃한 면을 활용한다"를 적용합니다. 정밀 조정 컨트롤(미세 다이얼 등)을 주 조작면이 아닌 옆면이나 뒷면에 두어 기본 조작과 섞이지 않게 합니다.

### 원리 #27 저가 단수명
- 하위 원리 "비싼 대상 하나를 값싸고 수명이 짧은 여러 개로 바꾼다"를 적용합니다. 복잡한 다기능 본체 하나 대신, 정밀 측정 조건별로 값싼 일회용·교체식 센서 팁이나 카트리지를 씁니다. 조건이 카트리지에 내장되어 사용자가 별도로 설정할 필요가 없습니다.
