## 적용 아이디어

### 원리 #22 전화위복
- 해로운 요인의 세기를 해가 되지 않을 정도까지 키우는 하위 원리를 적용합니다. 팬 소음을 저주파 대역 안에서 일정한 소리로 만들면 귀에 덜 거슬립니다. 임계 온도 근처에서 팬이 오르내리며 나는 소리를 없애고, 일정한 백색소음 수준으로 맞추는 식입니다.
- 해로운 요인을 다른 해로운 요인과 합쳐 서로 상쇄하는 하위 원리를 적용합니다. 액티브 노이즈 캔슬링으로 팬 소음에 역위상 소리를 더합니다. 소음이 소음을 지우는 구조입니다.
- 해로운 요인을 이용해 좋은 효과를 만드는 하위 원리를 적용합니다. 팬이 만드는 기류를 다른 부품(전원부·저장장치)의 냉각에도 함께 씁니다. 그러면 팬을 추가하지 않아도 됩니다.

### 원리 #35 매개변수 변화
- 온도를 바꾸는 하위 원리를 적용합니다. 열 관리 임계 온도를 높이거나, 부하가 낮을 때는 허용 온도를 올려 팬 회전수를 낮춥니다.
- 물리적 상태를 바꾸는 하위 원리를 적용합니다. 공랭을 액체 냉각이나 히트파이프(상변화)로 바꿔 팬 회전수 요구를 낮춥니다.
- 유연성의 정도를 바꾸는 하위 원리를 적용합니다. 블레이드를 유연한 소재로 만들거나 팬 프레임에 진동 흡수 소재를 씁니다.

### 원리 #2 추출
- 방해가 되는 성질을 대상에서 떼어내는 하위 원리를 적용합니다. 소음원인 팬을 사용자 근처에서 분리해 후면 방음 챔버나 원격 라디에이터에 둡니다. 예시의 "소음원을 방음 부스로 옮긴 컴프레서"와 같은 방향입니다.
- 필요한 성질만 골라내 쓰는 하위 원리를 적용합니다. 열이 집중되는 부위만 골라 국소 냉각하고, 나머지는 저속으로 돌립니다.

### 원리 #24 매개물
- 전달을 매개하는 대상을 두는 하위 원리를 적용합니다. 열을 팬 근처의 큰 방열판이나 히트파이프로 먼저 옮깁니다. 방열 면적이 커지면 같은 온도에서도 팬을 저속으로 돌릴 수 있습니다.
- 매개체를 임시로 붙여 쓰는 하위 원리를 적용합니다. 고부하 순간에만 열을 흡수하는 상변화 소재(PCM) 패드를 열 경로에 붙여 두고, 그동안 팬은 저속으로 유지합니다.
