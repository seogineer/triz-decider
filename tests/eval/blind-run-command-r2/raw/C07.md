## 적용 아이디어
### 원리 #15 역동성
- 공정마다 전용 설비를 두지 말고, 움직이는 여러 부분으로 나눈 범용 모듈 하나를 쓰세요. 예를 들어 로봇 암 하나에 그리퍼나 툴을 바꿔 끼우면, 공정 단계마다 대상에 맞게 스스로 바뀌는 구조가 됩니다(하위 원리 1·2). 이렇게 하면 부품 수와 구조가 줄어듭니다.
- 고정된 가이드나 지그를 가변형(각도·폭 조절)으로 바꿉니다(하위 원리 3). 품종별 고정구가 여러 벌 필요하던 것이 한 벌로 줄어듭니다.

### 원리 #24 매개물
- 공정마다 이송 장치를 따로 두는 대신, 제품을 싣고 다니는 팔레트나 캐리어를 매개물로 씁니다(하위 원리 1). 그러면 스테이션 쪽 이송·클램핑 기구가 단순해집니다.
- 매개체를 필요한 공정에서만 붙였다가 떼어 냅니다(하위 원리 2). 예를 들어 임시 지그나 가이드는 공용으로 돌려 씁니다.

### 원리 #10 사전 조치
- 부품을 공급하기 전에 미리 정렬·방향 맞춤·키팅을 해 두면, 설비 안의 정렬·검출 기구가 필요 없어집니다(하위 원리 1).
- 부품이 사용될 위치에 미리 놓이도록 매거진이나 트레이를 사용 순서대로 배열해 둡니다(하위 원리 2). 피더와 센서 수가 줄어듭니다.

### 원리 #35 매개변수 변화
- 부품이나 소재의 유연성을 바꿉니다(하위 원리 3). 예를 들어 위치 오차를 흡수하는 컴플라이언트 소재나 구조를 쓰면, 정밀 보정용 센서·액추에이터를 줄일 수 있습니다.
- 물리적 상태를 바꿔 이송 구조를 단순화할 수 있습니다(하위 원리 1). 예를 들어 분체나 소형 부품을 액상 또는 유체 상태로 공급하면 기계식 이송 부품이 줄어듭니다. 이 안은 공정에 맞는지 검토가 필요합니다.

### 원리 #13 역발상
- 공구나 헤드를 여러 축으로 움직이는 대신, 대상물을 움직이고 공구는 고정합니다(하위 원리 2). 그러면 이동축의 개수와 배선이 줄어듭니다.
- 대상을 뒤집거나 회전시켜 여러 면을 한 스테이션에서 처리합니다(하위 원리 3). 그러면 스테이션 수가 줄어듭니다.
