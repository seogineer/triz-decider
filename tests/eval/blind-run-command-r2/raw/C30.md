설치형 장비의 설치 부피를 줄이면 조립·세팅에 걸리는 시간이 늘고 조립이 어려워진다. (모순 문장은 확인 완료 상태라 질문 없이 진행했다.)

**조회 참고**
- #8×#25와 #8×#33 조합은 행렬에 원리가 없어 `empty_pairs`로 나왔다.
- #8×#25는 `unverified_cell` 경고도 붙었다. 자료 간 값이 달라 확정하지 못한 셀이므로, 이 조합은 검증된 데이터가 없어 조회할 수 없다.
- 그래서 부피(#8)와 시간(#25)을 직접 잇는 결과는 없다. 위 순위는 면적 #6과 조립 용이성 #32 조합에 기대는 부분이 크다.

## 적용 아이디어
### 원리 #35 매개변수 변화
- 유연성의 정도를 바꾼다: 배관, 케이블, 덕트를 딱딱한 배관 대신 유연한 호스와 플렉스 케이블로 바꾼다. 좁은 공간에서도 정렬 없이 연결할 수 있다.
- 물리적 상태를 바꾼다: 접착·고정 작업에는 볼트 체결 대신 빠르게 굳는 접착제나 폼을 쓴다. 공구 접근 공간이 필요 없어 부피와 시간을 둘 다 줄인다.

### 원리 #4 비대칭
- 대칭인 형태를 비대칭으로 바꾼다: 커넥터, 브래킷, 모듈에 한쪽으로만 꽂히는 형상을 준다. 방향을 확인하거나 시행착오를 하지 않아 조립 오류와 세팅 시간이 줄어든다.
- 모듈마다 비대칭 키 형상을 다르게 두면, 촘촘한 배치에서도 잘못된 자리에 조립되는 일을 막는다.

### 원리 #16 과부족 조치
- 조금 덜 하거나 더 하는 쪽을 택한다: 정밀 정렬을 100% 요구하지 말고 약간의 공차를 두고 조립한다. 조립 후 자동 캘리브레이션으로 남는 오차를 보정하면 손 조정 시간이 줄어든다.

### 원리 #10 사전 조치
- 필요한 변화를 먼저 수행해 둔다: 공장에서 서브어셈블리, 배선, 튜빙을 미리 조립하고 시험해서 출하한다. 현장에서는 접속과 고정만 남긴다.
- 대상을 가장 편한 자리에 미리 둔다: 접힌 상태로 출하하는 접이식·전개식 구조로 만든다. 설치 위치에서는 펼쳐 잠그기만 하면 되고, 파라미터와 설정값은 프리셋으로 미리 넣어 둔다.
