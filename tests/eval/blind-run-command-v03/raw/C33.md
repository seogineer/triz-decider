## Application ideas
### Principle #35 Parameter Changes
- **Change its degree of flexibility:** Keep the housing rigid where it carries load, such as the frame and corners. Make the parts the user touches (buttons, hinges, latches, grips) flexible or compliant, so they still move easily.
- **Change the physical state, concentration or viscosity:** Use a stiffness-variable material or structure. A latch could be stiff when locked and easy to release when the user squeezes or twists it.

### Principle #32 Color Changes
- **Change the colour of the object or its surroundings:** The reinforced housing now hides how to operate it, so colour-code the operating points (release tabs, handles, opening direction) against the housing body.
- **Mark the object with tags:** Add luminescent or contrasting markings to the access points, so the controls are found at a glance without trial and error.

### Principle #30 Flexible Shells and Thin Films
- **Use flexible shells or thin films in place of bulky structures:** Don't thicken the whole shell. Use a thin rigid frame with a flexible outer skin, so the strength comes from structure and the added bulk goes away.
- **Isolate the object from its environment with a flexible membrane:** Cover the control area with a flexible membrane (for example a sealed rubber overlay for buttons), so it is protected and still easy to press.

### Principle #2 Taking Out (Extraction)
- **Pull the disturbing part out of the object:** Move the reinforcement that gets in the way (thick walls, extra screws) away from the operating zone. Reinforce only around the outer frame and mounting points.
- **Keep only the part that is truly needed:** Put the frequently used interface (buttons, ports, battery door) in its own lightly built module. Only that module needs to be easy to operate.
